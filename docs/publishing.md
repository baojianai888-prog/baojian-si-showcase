# 公开发布规范

发布前逐项完成：

- 内容确实适合公开，且符合所有者本次授权的范围。
- 客户项目获得明确的公开展示授权；没有授权则不发布。
- 文案、图像、音频、字体和作品均有相应使用权。
- 已去除客户身份信息、内部报价、合同、凭证和隐藏元数据。
- 项目状态、参与范围、指标和引用均可核实；概念演示明确标识。
- 图片与文档已经人工打开检查，链接指向允许公开的地址。
- 提交差异经过审核，作品索引只登记实际发布的内容。

作品索引每条包含 id、title、path、type、published_at、rights_summary。
授权原件通过私密渠道保管；公开索引只保存不含个人信息的摘要。
未发布模板不加入作品索引。禁止从其他资料库进行未经审核的自动同步。

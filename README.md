# 宝见 SI · 公开展示资料

这里用于整理宝见 SI 可公开的品牌介绍与作品资料。

**当前状态：展示仓库已初始化，暂无已发布作品或客户案例。**
本仓库中的模板只用于后续整理，不代表已有项目成果、客户合作或效果承诺。

## 资料目录

| 目录 | 内容 |
| --- | --- |
| brand/ | 经确认的品牌公开资料 |
| works/ | 已获授权且经审核的作品；当前为空 |
| assets/ | 可公开素材的管理说明 |
| templates/ | 作品说明模板 |
| docs/ | 发布与授权规范 |

作品发布前须完成 [公开审核](docs/publishing.md)。客户敏感信息、内部资料和凭证不得进入本仓库。
公开可见不代表所有素材均可任意商用；使用范围见 [素材权利说明](RIGHTS.md)。

本仓库用于资料展示，当前不包含已部署网站或在线 AI 服务。
